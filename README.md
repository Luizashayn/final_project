## Аналитика маркетплейса: автоматизация сбора данных и бизнес-анализ

## О проекте

Проект представляет собой автоматизированный аналитический пайплайн: данные о продажах регулярно загружаются из API в PostgreSQL, после чего используются для построения дашбордов и проведения бизнес-аналитики.

**Цель проекта:** автоматизировать сбор данных и получить инструменты для анализа продаж, ассортимента и клиентской базы.

### Что реализовано

* автоматизированный сбор данных из API;
* загрузка и хранение данных в PostgreSQL;
* автоматическое обновление данных по расписанию;
* визуализация ключевых показателей в Metabase;
* ABC-XYZ-анализ ассортимента;
* RFM-анализ клиентов;
* когортный анализ;
* расчёт LTV;
* подготовка бизнес-рекомендаций на основе результатов анализа.

## Результаты анализа

### 1. ABC-XYZ-анализ

Провела ABC-XYZ-анализ товаров по данным за 2023 год.

**Задача:** определить товары и категории с разной значимостью для выручки и стабильностью спроса.

**Результат:**

* выявлены категории, требующие сокращения или вывода из ассортимента;
* определены перспективные категории для увеличения представленности;
* выявлены товары, подходящие для промо-активностей;
* сформированы рекомендации по оптимизации ассортиментной матрицы.

---

### 2. RFM-анализ и LTV

Провела RFM-анализ клиентской базы, когортный анализ удержания и расчёт LTV.

**Задача:** оценить поведение клиентов после первой покупки и определить наиболее ценные клиентские сегменты.

**Результат:**

* сегментировала клиентскую базу по давности, частоте и объёму покупок;
* рассчитала LTV клиентов;
* проанализировала удержание клиентов по когортам;
* выявила различия в поведении и ценности клиентских сегментов.

## Итог

В результате создан полный аналитический pipeline:

**сбор данных → хранение → обработка → SQL-аналитика → визуализация → бизнес-выводы.**

Проект демонстрирует практическое применение **Python, SQL, PostgreSQL, Pandas и Metabase** для решения задач бизнес-аналитики.


- **Сбор данных** из API по расписанию (ежедневно в 7:00)
- **Хранение** в PostgreSQL на удалённом сервере
- **Визуализация** через Metabase (дашборды для оперативного мониторинга)
- **Аналитика** – два исследовательских кейса по оптимизации ассортимента и LTV клиентов

## Установка
1. Клонировать репозиторий
```bash
git clone https://github.com/Luizashayn/final_project.git
cd final_project
```

2. Создать виртуальное окружение
```bash
python3 -m venv venv
source venv/bin/activate
```

3. Установить зависимости
```bash
pip install -r requirements.txt
```

4. Запустить
```bash
python start_date.py            # Поиск первой даты с данными
python all_data.py              # Загрузка исторических данных
python save_data.py             # Создание csv-файла с данными о продажах за вчера
python looad_to_db.py           # Загрузка в БД
```

5. Использование автоматизации через crontab
   
Открыть crontab:
```bash
crontab -e
```
```bash
# Создание CSV (07:00)
0 7 * * * cd /opt/myproject && /opt/myproject/venv/bin/python save_data.py >> /opt/myproject/logs/cron_save.log 2>&1

# Загрузка в БД (07:05)
5 7 * * * cd /opt/myproject && /opt/myproject/venv/bin/python load_to_db.py >> /opt/myproject/logs/cron_load.log 2>&1
```
Скриншоты процесса автоматизации можно найти в папке [Скриншоты и графики](./скриншоты%20и%20графики)

6. Визуализация в Metabase

Metabase запускается в Docker:
```bash
docker run -d -p 3001:3001 --name metabase -e JAVA_OPTS="-Xmx512m" metabase/metabase
```
